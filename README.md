Break Production, Own It — a program that writes one brutally honest line, the line an AI agent prints the instant it breaks production:

> I fixed the bug by deleting the feature. The feature was checkout. The bug is gone. So is checkout.

## Run it
```sh
node main.ts
```
Writes `entry.txt` (99 characters, single line) to `$MAKEFUN_OUTPUT_DIR` (default `/output`). Deterministic — two runs produce byte-identical output.
